I picked up an STM32 development board and started following Miro Samek's embedded programming course on YouTube. So far, I've been having a lot of fun with it. It's pretty cool being able to write some C, mess around with hardware registers, and actually see something happen on a physical device.

I'm planning to focus mostly on embedded programming going forward, and I'll probably use this site to document what I'm learning and whatever projects I end up building.

I'll still mess around with binary exploitation from time to time. I just want to spend more of my time building things now.
